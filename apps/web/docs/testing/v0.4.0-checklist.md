# LeadPilot AI CRM — v0.4.0 Contact Management Verification Checklist

Use this checklist to perform verification of the Customer Management module against your live Supabase environment.

---

## Verification Test Cases

| Test Case | Procedure | Expected Result | Status |
| :--- | :--- | :--- | :---: |
| **1. Create Contact** | Click **+ Add Contact** on `/contacts`. Enter details and submit. | Contact created in Supabase `contacts` table and appended to UI. | [x] |
| **2. Edit Contact** | Click edit on any contact card. Modify email or designation and save. | Contact record updated in database and re-rendered. | [x] |
| **3. Delete Contact** | Select delete action on contact card $\rightarrow$ confirm. | Contact record removed from database and UI. | [x] |
| **4. Favorite Contact** | Click Star icon on contact card. | `is_favorite` toggled in database; star fills gold. | [x] |
| **5. Archive Contact** | Select archive action on contact card. | Contact `status` updated to `ARCHIVED`. | [x] |
| **6. Lead Conversion** | Open a lead in `/leads` drawer and click **Convert to Contact**. | Contact created referencing `lead_id`; lead preserved with `QUALIFIED` status. | [x] |
| **7. Contact Timeline** | Open contact details drawer $\rightarrow$ select **Timeline** tab. | Chronological timeline stream rendered with `Lead Created` and `Lead Converted` events. | [x] |
| **8. Refresh Persistence** | Refresh the browser on `/contacts`. | All contact updates, favorites, and conversions persist after page reload. | [x] |
| **9. Unit Test Suite** | Execute `npx jest src/tests/unit/contact-repository.test.ts`. | All unit tests pass. | [x] |
