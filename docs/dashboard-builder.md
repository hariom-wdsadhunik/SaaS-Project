# LeadPilot AI CRM — Custom Dashboard Builder & Widget Studio

**Module:** Custom Dashboard Layout Engine  
**Version:** v3.6.0  

---

## 1. Supported Widget Chart Types

1. `LINE` (Multi-variable trend series)
2. `BAR` (Categorical metric comparisons)
3. `AREA` (Cumulative financial growth)
4. `PIE` (Share distribution)
5. `DONUT` (Lead source & channel breakdown)
6. `FUNNEL` (Sales pipeline conversion steps)
7. `KANBAN_METRICS` (Deal stage velocity)
8. `HEATMAP` (Activity density by day/hour)
9. `TABLE` (Granular data grid)
10. `TREND_CARD` (Single KPI highlight card with % change)
