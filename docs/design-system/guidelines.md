# LeadPilot AI CRM — Enterprise Design System & Guidelines

This document details the design system architecture, visual design tokens, component library usage, and accessibility standards for LeadPilot AI CRM.

## Visual Tokens Philosophy

- **Dark-Mode First**: Linear precision, `zinc-950` dark backgrounds, `zinc-800` subtle border lines, and `indigo-500` brand accents.
- **Micro-Animations**: Framer-motion / Tailwind CSS 150ms-200ms transitions.
- **Typography**: Inter / Outfit fonts with mono font support for data fields.

## Storybook

Components are documented in Storybook stories located in `src/design-system/stories/`.
