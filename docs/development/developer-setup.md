# LeadPilot AI CRM — Developer Setup Guide

This guide outlines setting up your local environment for contributing to LeadPilot AI CRM.

## Prerequisites

- Node.js 20.x or higher
- npm 10.x or higher
- Git

## Quickstart

```bash
git clone https://github.com/leadpilot-ai/leadpilot-crm.git
cd leadpilot-ai/leadpilot-frontend
npm install
npm run dev
```

Visit `http://localhost:3000` to view the application locally.
