# LeadPilot AI CRM — Release Notes v0.6.5

**Release Date:** July 26, 2026  
**Module:** Platform Infrastructure Sprint  

---

## 1. Release Summary

Release **v0.6.5** delivers a comprehensive, production-ready Platform Infrastructure foundation for LeadPilot AI CRM. This architecture powers real-time WebSockets, event-driven reactive domain communication, multi-channel notifications, job queues, user presence, and centralized audit logging.

---

## 2. Delivered Modules & Components

1. **Supabase Realtime Engine (`src/platform/realtime/`)**
   - Live entity streaming for `leads`, `deals`, `contacts`, `tasks`, `appointments`, and `dashboard`.
   - Automatic connection retry and duplicate subscription prevention.

2. **Domain Event Bus (`src/platform/events/`)**
   - Pub/sub broker for strongly-typed domain events (`LeadCreated`, `LeadUpdated`, `TaskCompleted`, `AppointmentScheduled`, `DealWon`).

3. **Notification Engine (`src/platform/notifications/`)**
   - In-App notifications, preference filtering, and architecture abstractions for Email, SMS, WhatsApp, and Push.
   - Interactive UI `NotificationCenter` integrated into navbar.

4. **Background Job Queue & Scheduler (`src/platform/jobs/`)**
   - Job queue supporting background tasks, retry policies, and exponential backoff calculations.

5. **User Presence (`src/platform/presence/`)**
   - Room and global user presence tracking (`ONLINE`, `OFFLINE`, `AWAY`, `BUSY`, typing state).

6. **Centralized Audit Log Stream (`src/platform/audit/`)**
   - Real-time audit log buffer capturing entity changes and authentication events.

7. **AI Copilot Event Integration**
   - `AIOrchestrator` subscribes to domain events to generate automated follow-up suggestions.
