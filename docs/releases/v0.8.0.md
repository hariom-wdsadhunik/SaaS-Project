# LeadPilot AI CRM — Release Notes v0.8.0

**Release Date:** July 26, 2026  
**Module:** Intelligent Document Management Platform Sprint  

---

## 1. Release Overview

Sprint **v0.8.0** delivers an enterprise-grade Intelligent Document Management Platform with Supabase storage abstractions, versioning history, SHA-256 checksum validation, AI OCR text extraction pipelines, automatic `contact_timeline` appending, and versioned `/api/v1/` route handlers.

---

## 2. Key Delivered Features

### A. Database Migration & RLS ([`supabase/migrations/20260726170000_create_document_tables.sql`](file:///c:/Users/Hari%20Om%20Kumar/Desktop/GitHub%20Projects/SaaS%20Project/leadpilot-ai/supabase/migrations/20260726170000_create_document_tables.sql))
- Core tables: `folders`, `documents`, `document_versions`, `document_tags`, `document_permissions`, `document_previews`.
- Strict RLS policies enforced (**0 `USING (true)` policies**).

### B. Storage Subsystem (`src/platform/storage/`)
- `StorageService`, `DocumentUploader`, `DocumentDownloader`, `DocumentPreviewGenerator`, `ChecksumValidator`, `FileValidator`.

### C. Supabase Repository & Contact Timeline Auto-Append
- `SupabaseDocumentRepository` executing live queries against Supabase PostgreSQL.
- Automatically appends `Upload`, `Rename`, `Share`, `Delete`, and `Restore` events to `contact_timeline`.

### D. AI Copilot Document Tool (`src/domain/ai/tools/DocumentTool.ts`)
- Registered `document_intelligence_tool` for OCR text extraction, document summaries, knowledge extraction, and RAG vector store lookups.

### E. Versioned API Endpoints (`src/app/api/v1/`)
- Versioned endpoints: `/api/v1/documents`, `/api/v1/folders`, `/api/v1/uploads`, `/api/v1/shares`.
