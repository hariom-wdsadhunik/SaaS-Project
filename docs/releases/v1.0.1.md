# LeadPilot AI CRM — Release Notes v1.0.1 (Launch & Product Readiness)

**Release Date:** July 26, 2026  
**Sprint:** Launch & Product Readiness  

---

## Highlights

- **First Run Experience (`OnboardingWizard.tsx`)**: Step-by-step welcome wizard, organization setup, team invitation, and sample data loader (`SampleDataLoader.ts`).
- **Product Tour Framework (`ProductTourService.ts`)**: Interactive guided tours for Dashboard, Leads, Deals, Calendar, Documents, Communication, Analytics, and AI Workspace.
- **Demo Mode (`DemoModeService.ts`)**: Interactive demo workspace state generator for prospective buyers.
- **Error Experience & Offline UX**: Custom branded 404 page (`not-found.tsx`), 500 error boundary (`error.tsx`), and network offline banner (`OfflineBanner.tsx`).
- **Accessibility Hardening (`accessibility.ts`)**: Screen reader announcements and keyboard focus trapping.
- **Launch Documentation**: Added `GettingStarted.md`, `AdministratorGuide.md`, and `UserGuide.md`.
