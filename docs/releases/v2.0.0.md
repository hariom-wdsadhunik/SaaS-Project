# LeadPilot AI CRM — Release Notes v2.0.0 (Brand Identity & Design System)

**Release Date:** July 26, 2026  
**Milestone:** Brand Identity & Enterprise Design System  

---

## Highlights

- **Brand Foundation (`docs/design/brand-foundation.md`)**: Brand vision, values, tone of voice, story, and taglines.
- **Design Tokens (`src/styles/tokens.css`)**: Centralized CSS tokens for colors, typography scales, spacing, border radii, elevation shadows, and dark/light themes.
- **Component Library Primitives (`src/components/ui/`)**: `Button`, `Input`, `Card`, `Badge`, `Modal`, and `CommandPalette` (⌘K search).
- **CRM Layout Shell System (`src/components/layout/AppLayout.tsx`)**: Responsive top navigation, collapsible mobile menu, and main content grid.
- **Design System Guide (`DESIGN.md`)**: Complete token and component usage reference manual.
