# LeadPilot AI CRM — Release Notes v3.4.0 (Workflow Automation Engine)

**Release Date:** July 30, 2026  
**Milestone:** Enterprise Visual Workflow Automation Platform  

---

## Highlights

- **Visual Workflow Automation Engine**: Event-driven automation rule builder with 14 trigger types, AND/OR condition evaluation, and 13 action handlers.
- **7 Pre-Built Automation Templates**:
  1. `New Lead Follow-up`
  2. `Lead Auto-Assignment`
  3. `Deal Won Celebration`
  4. `Deal Lost Recovery`
  5. `Appointment Reminder`
  6. `Payment Reminder`
  7. `Inactive Lead Re-engagement`
- **Execution Audit Trail**: Real-time logging of execution time, latency, result, retries, and errors.
- **Automation UI Sub-App**:
  - `/automation` (Command Center Overview & Stats)
  - `/automation/workflows` (Workflows List & Interactive Editor)
  - `/automation/templates` (1-Click Templates Gallery)
  - `/automation/history` (Execution Audit Log)
- **Documentation**:
  - `docs/workflow-engine.md`
  - `docs/automation-architecture.md`
  - `docs/workflow-api.md`
