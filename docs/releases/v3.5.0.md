# LeadPilot AI CRM — Release Notes v3.5.0 (Enterprise Integrations Hub)

**Release Date:** July 30, 2026  
**Milestone:** Enterprise Integrations Hub & Connector Framework  

---

## Highlights

- **Modular Connector Framework**: Centralized connector registry supporting health checks, manual/auto sync scheduling, and credentials storage.
- **Google Workspace Integration**: OAuth 2.0 sync for Google Calendar, Gmail API, and Google Contacts.
- **Microsoft 365 Integration**: Microsoft Graph API sync for Outlook Calendar, Outlook Mail, and Microsoft Contacts.
- **Unified Messaging Providers**: WhatsApp Business Cloud API, Twilio SMS, SendGrid Email, and Nodemailer SMTP adapters.
- **Stripe Payments Extension**: Subscription status, payment history, and webhook signature verification.
- **Webhook Management Engine**: Incoming and outgoing HTTP webhooks with HMAC SHA-256 signatures, retry queue, and ping testing.
- **Scoped API Keys**: Key generation, rotation, expiration, and granular scope access controls.
