# LeadPilot AI CRM — Report Export & Scheduling Architecture

**Module:** Multi-Format Exporter & Automated Scheduler

## 1. Export Formats

- **CSV:** Raw filtered entity tabular exports.
- **Excel (.xlsx):** Multi-sheet formatted workbooks with summary headers.
- **PDF:** Executive PDF reports formatted with branding guidelines.
- **JSON:** REST API compliant structured data payloads.
