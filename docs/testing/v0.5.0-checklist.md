# LeadPilot AI CRM — v0.5.0 Task & Activity Management Verification Checklist

Use this checklist to perform manual and automated verification of the Task & Activity Management module.

---

## Manual QA Verification Matrix

| Test Case | Procedure | Expected Result | Status |
| :--- | :--- | :--- | :---: |
| **1. Create Task** | Click **Create Task** on `/tasks`. Fill in title, due date, priority, category, and submit. | Task created in Supabase `tasks` table and rendered in UI. | [x] |
| **2. Edit Task** | Click edit on a task item. Modify priority or due date and save. | Task record updated in database and re-rendered. | [x] |
| **3. Delete Task** | Select delete action on task dialog. | Task record removed from database and UI. | [x] |
| **4. Assign Task** | Select reassign broker on task item. | `assigned_to` field updated; `Task Assigned` activity recorded. | [x] |
| **5. Complete Task** | Check complete action on task item. | `status` updated to `COMPLETED`; `completed_at` timestamp recorded. | [x] |
| **6. Archive Task** | Select archive action on task item. | `status` updated to `ARCHIVED`. | [x] |
| **7. Task Search & Filters** | Type query in search bar or select priority filter. | Tasks filtered dynamically by search query, status, and priority. | [x] |
| **8. Kanban View** | Switch view mode to **Kanban** on `/tasks` toolbar. | Tasks grouped into `TODO`, `IN_PROGRESS`, `WAITING`, `COMPLETED` columns. | [x] |
| **9. Table View** | Switch view mode to **Table** on `/tasks` toolbar. | Tabular list rendered with sortable columns and action menus. | [x] |
| **10. Timeline Integration** | Create/complete a task linked to a contact. Open contact drawer $\rightarrow$ **Timeline**. | Task event automatically appended to `contact_timeline`. | [x] |
| **11. Dashboard Widgets** | Navigate to `/dashboard`. | `Today's Tasks`, `Overdue Tasks`, `Upcoming Tasks`, `Completion Rate` widgets rendered. | [x] |
| **12. Unit Test Suite** | Execute unit test files under `src/tests/unit/`. | All task repository, comments, and timeline tests pass. | [x] |
