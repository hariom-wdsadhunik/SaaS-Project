# LeadPilot AI CRM — v0.6.0 Calendar & Appointment Management Checklist

Use this checklist to perform manual and automated verification of the Calendar & Appointment Management module.

---

## QA Verification Matrix

| Test Case | Procedure | Expected Result | Status |
| :--- | :--- | :--- | :---: |
| **1. Create Appointment** | Click **Schedule Appointment** on `/appointments` or `/calendar`. Fill in title, time, type, location, and submit. | Appointment record created in Supabase database and rendered in UI. | [x] |
| **2. Edit Appointment** | Click edit on appointment item. Modify start/end time or meeting link and save. | Appointment updated in database and re-rendered. | [x] |
| **3. Confirm Appointment** | Click confirm action on appointment item. | Status updated to `CONFIRMED`; `Confirmed` activity recorded. | [x] |
| **4. Complete Appointment** | Click complete action on appointment item. | Status updated to `COMPLETED`; timeline event appended. | [x] |
| **5. Cancel Appointment** | Select cancel action on appointment item with reason. | Status updated to `CANCELLED`; cancellation reason recorded. | [x] |
| **6. Calendar Month View** | Switch view to **Month View** on `/calendar`. | Events displayed in monthly calendar grid. | [x] |
| **7. Calendar Week & Day Views**| Switch view to **Week / Day View** on `/calendar`. | Events positioned accurately by start and end hours. | [x] |
| **8. Calendar Agenda View** | Switch view to **Agenda View** on `/calendar`. | Chronological agenda list rendered with date headers. | [x] |
| **9. Contact Timeline Auto-Append** | Create/complete an appointment linked to a contact. Open contact drawer $\rightarrow$ **Timeline**. | Appointment event automatically appended to `contact_timeline`. | [x] |
| **10. Dashboard Widgets** | Navigate to `/dashboard`. | `Today's Meetings`, `Upcoming Meetings`, `This Week`, `No Shows`, `Completed` widgets rendered. | [x] |
| **11. Unit Test Suite** | Execute `src/tests/unit/appointment-*.test.ts` and `calendar-view.test.ts`. | All appointment repository, reminder, timeline, and view tests pass. | [x] |
