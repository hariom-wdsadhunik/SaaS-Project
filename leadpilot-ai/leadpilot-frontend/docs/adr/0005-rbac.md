# ADR 0005: Role-Based Access Control (RBAC) Architecture

**Status:** Accepted  
**Date:** July 26, 2026  

## Context
Multi-broker real estate CRM operations require strict authorization controls across system roles (`ADMIN`, `MANAGER`, `BROKER`, `AGENT`, `VIEWER`).

## Decision
We enforce a dual-layer RBAC mechanism:
1. **Database Layer:** `public.roles` and `public.user_roles` mapping users to system permissions.
2. **Application Layer:** `AuthProvider` & `RBACContext` caching user roles and guarding UI components and protected routes.

## Consequences
- Prevents unauthorized data access at API and client presentation boundaries.
