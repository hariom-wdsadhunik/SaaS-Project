# LeadPilot AI CRM — Release v0.2.0 (Authentication & RBAC Integration)

## 1. Feature Highlights

- **Supabase Authentication Engine:** Integrated real Supabase Auth supporting Email/Password sign-in, session persistence, automatic token refresh, password reset, and logout.
- **RBAC Engine Integration:** Seamlessly connected Supabase Auth user sessions to LeadPilot's multi-tenant RBAC engine (`ADMIN`, `MANAGER`, `BROKER`, `AGENT`, `VIEWER`).
- **Protected Routes & Next.js Middleware:** Automated server-side and client-side route protection across all dashboard modules (`/dashboard`, `/leads`, `/deals`, `/calendar`, `/tasks`, `/communication`, `/copilot`, `/properties`, `/contacts`, `/appointments`).
- **Telemetry Audit Logging:** Integrated `platformAuditLogger` for auth telemetry events (`User Login`, `Logout`, `Failed Login`, `Session Expired`, `Permission Denied`).

## 2. Database Schema & RLS Migrations

- Created `supabase/migrations/20260726103000_create_auth_rbac_tables.sql` establishing:
  - `public.profiles` (`id` referencing `auth.users`, `full_name`, `email`, `organization_id`)
  - `public.roles` (`id`, `name`, `description`)
  - `public.user_roles` (`user_id`, `role_id`)
- **Row Level Security (RLS):** All tables strictly enforce `auth.uid()` checks (NO `USING (true)` policies).
