# LeadPilot AI CRM — Release Notes v0.3.1

**Release Date:** July 26, 2026  
**Module:** Complete Production Authentication Flow & Live Supabase Auth Engine  

---

## Key Features & Enhancements

### 1. Dedicated Sign-Up Workspace (`/register`)
- Complete user registration form requiring **Full Name**, **Work Email**, **Password**, and **Confirm Password**.
- Live Zod form validation with built-in password strength calculation meter.
- Invokes `supabase.auth.signUp()` with metadata options (`full_name`, `role: "BROKER"`).
- Supports post-registration email verification prompt and immediate workspace redirection.

### 2. Email Verification Handling (`/verify-email`)
- Dedicated callback page handling email verification status tokens from Supabase Auth.
- Handles success state, link expiration (`otp_expired`), and invalid link tokens.

### 3. Login Workspace Improvements (`/login`)
- Added direct navigation links for **Create Account** (`/register`) and **Forgot Password** (`/forgot-password`).
- Enhanced user-friendly error alerts surfacing explicit authentication failure reasons.

### 4. Self-Service Password Recovery & Reset (`/forgot-password`, `/reset-password`)
- **/forgot-password:** Accepts user email and triggers `supabase.auth.resetPasswordForEmail()`. Includes 60-second resend throttle timer.
- **/reset-password:** Handles Supabase recovery session and invokes `supabase.auth.updateUser({ password })`.

### 5. Automated Database Profile & RBAC Synchronization
- Updated PostgreSQL trigger `handle_new_user()` to automatically populate `public.profiles` with `full_name` and `email`.
- Assigns default role **`BROKER`** to all self-registered users via `public.user_roles`.
- Includes `ON CONFLICT (id) DO UPDATE` to prevent duplicate profile creation errors.

---

## Security Compliance

- **No Service Role Leakage:** All authentication operations run strictly via public anon key through `src/lib/supabase/client.ts`.
- **Singleton Client Enforcement:** Single shared Supabase client prevents duplicate `GoTrueClient` instance warnings.
- **Role Scoping:** New user accounts are restricted to the default `BROKER` system role.
