# LeadPilot AI CRM — v0.3.1 Authentication Verification Checklist

Use this checklist to perform manual end-to-end verification of the authentication flow against your live Supabase project (`epxgsurlzigtwlaqyvlv.supabase.co`).

---

## Verification Test Cases

| Test Case | Procedure | Expected Result | Status |
| :--- | :--- | :--- | :---: |
| **1. Register New Account** | Navigate to `/register`. Fill in name, email, password, confirm password, and click **Register Account**. | Account created in `auth.users`, email verification prompt or automatic login triggered. | [x] |
| **2. Default Role Assignment** | Check Supabase SQL Editor: `SELECT * FROM public.user_roles;` for the new user ID. | New user is assigned `role_id = 'BROKER'`. | [x] |
| **3. Profile Creation** | Check Supabase SQL Editor: `SELECT * FROM public.profiles;` for the new user ID. | `full_name` and `email` populated without duplicate key errors. | [x] |
| **4. Email Verification Link** | Click verification link sent by Supabase (or navigate to `/verify-email`). | Screen displays "Email Verified Successfully" with Sign In redirect button. | [x] |
| **5. Login Flow** | Navigate to `/login`. Enter registered credentials and submit. | Successful toast displays; user redirected to `/dashboard`. | [x] |
| **6. Session Persistence** | Refresh the browser on `/dashboard` or open a new tab. | User session is preserved; no login redirect required. | [x] |
| **7. Forgot Password Flow** | Navigate to `/forgot-password`. Enter registered email address and submit. | Confirmation message shown; 60s resend timer activates. | [x] |
| **8. Reset Password Flow** | Follow recovery link to `/reset-password`. Enter new password and submit. | Password updated successfully; user redirected to `/login`. | [x] |
| **9. Logout Flow** | Click avatar menu in workspace header $\rightarrow$ **Sign Out**. | Active session cleared; user redirected to `/login`. | [x] |
| **10. Guest Route Guarding** | Attempt to visit `/login` or `/register` while authenticated. | User automatically redirected to `/dashboard`. | [x] |
| **11. Protected Route Guarding** | Clear browser session and attempt to visit `/dashboard` or `/leads`. | User automatically redirected to `/login?expired=true`. | [x] |
